# Dokumentation: Installation von SecureSafe und der Browser-Erweiterung (Windows)

## 1. Installation der SecureSafe-Desktop-Anwendung

### Schritt 1: Download der Anwendung
1. Öffnen Sie einen Webbrowser (z. B. Chrome, Edge oder Firefox) auf Ihrem Windows-PC.
2. Besuchen Sie die offizielle Website von **SecureSafe**: [https://www.securesafe.com](https://www.securesafe.com).
3. Navigieren Sie zum **Download-Bereich**.
4. Wählen Sie die Version für **Windows** aus und klicken Sie auf den **Download-Button**.

### Schritt 2: Installation der Anwendung
1. Nach Abschluss des Downloads öffnen Sie die heruntergeladene Installationsdatei (z. B. `SecureSafeInstaller.exe`).
2. Folgen Sie den Anweisungen im Installationsassistenten:
   - Wählen Sie das Installationsverzeichnis aus.
   - Akzeptieren Sie die Lizenzvereinbarung.
   - Klicken Sie auf **Installieren**, um die Installation zu starten.
3. Nach erfolgreicher Installation starten Sie die Anwendung über das Desktop-Icon oder das Startmenü.

### Schritt 3: Einrichten des Kontos
1. Melden Sie sich mit Ihrem bestehenden SecureSafe-Konto an oder erstellen Sie ein neues Konto.
2. Konfigurieren Sie Sicherheitsoptionen wie:
   - Aktivierung der Zwei-Faktor-Authentifizierung (2FA).
   - Sicherung wichtiger Daten.

---

## 2. Installation der SecureSafe-Browser-Erweiterung

### Schritt 1: Download der Browser-Erweiterung
1. Öffnen Sie den Browser Ihrer Wahl (z. B. Google Chrome, Mozilla Firefox oder Microsoft Edge).
2. Besuchen Sie den jeweiligen **Web Store** für Erweiterungen:
   - **Google Chrome Web Store**: [https://chrome.google.com/webstore](https://chrome.google.com/webstore)
   - **Mozilla Firefox Add-ons**: [https://addons.mozilla.org](https://addons.mozilla.org)
   - **Microsoft Edge Add-ons**: [https://microsoftedge.microsoft.com/addons](https://microsoftedge.microsoft.com/addons)
3. Suchen Sie nach **SecureSafe Password Manager** in der Suchleiste des Stores.
4. Klicken Sie auf **Hinzufügen** oder **Installieren**, um die Erweiterung herunterzuladen und zu aktivieren.

### Schritt 2: Einrichten der Browser-Erweiterung
1. Nach der Installation erscheint ein **SecureSafe-Icon** in der Symbolleiste des Browsers.
2. Klicken Sie auf das Icon und melden Sie sich mit Ihrem SecureSafe-Konto an.
3. Folgen Sie den Anweisungen, um:
   - Ihre gespeicherten Passwörter zu synchronisieren.
   - Die automatische Passwortausfüllung und Speicherung zu aktivieren.
4. Testen Sie die Erweiterung, indem Sie sich auf einer Webseite einloggen – SecureSafe füllt die Login-Daten automatisch aus.

---

## 3. Fazit
Mit diesen Schritten haben Sie **SecureSafe** auf Ihrem Windows-PC und die **Browser-Erweiterung** erfolgreich installiert. Beide Komponenten bieten Ihnen eine sichere Möglichkeit, Passwörter und sensible Daten zu verwalten und zu schützen.
